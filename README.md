Entry for the [Fortune Cookie Wisdom for Developers](https://make.fun/competitions/u-gentle-koala-60-fortune-cookie-wisdom-for-developers-025ccf44) bounty on [make.fun](https://make.fun).

`main.ts` writes one original fortune-cookie line for a software developer
(120 characters or fewer) to `/output/entry.txt`:

> The legacy code you curse today was written by someone exactly as tired as you.

Run it with Node 22.18 or later:

```sh
node main.ts
```
